# CI Auto-Builds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automate building + releasing the OpenCut offline Windows installer via GitHub Actions — tag `v*` publishes a Release with the installer; PRs/pushes build + smoke-test.

**Architecture:** One `windows-latest` GitHub Actions workflow runs the existing `bun run desktop:build`, gates on a bundle-completeness smoke test (boots the standalone server, curls every bundled asset), then either uploads the installer as an artifact (PR/push) or publishes a GitHub Release (tag). Two build scripts are hardened so the model fetch is reliable under CI caching.

**Tech Stack:** GitHub Actions, Node ESM scripts, Bun, Tauri v2, Next.js standalone server.

**Spec:** `docs/superpowers/specs/2026-09-21-ci-auto-builds-design.md`

## Global Constraints
- Repo: https://github.com/Shmubbier/opencut-offline (branch `master`).
- Windows x64 only. Installer path: `src-tauri/target/release/bundle/nsis/OpenCut_<ver>_x64-setup.exe`.
- `bun run desktop:build` is the single build entrypoint; do not duplicate its logic in CI.
- The Whisper model (`public/models/…`), ort wasm (`public/ort/`), and node sidecar are gitignored and regenerated by the build — never commit them.
- Bun version: `1.2.18` (repo `packageManager`).
- No code signing in this plan; the installer stays unsigned.
- Commit after each task.

## File Structure

- [ ] **Step 1: Rewrite the `download` function in `scripts/fetch-whisper.mjs` to check completeness**

Replace the existing `download` function with one that re-downloads when the local size doesn't match the remote `Content-Length` (HF also exposes `x-linked-size`). Keep the rest of the file (imports, `HF_ID`, `BASE`, `OUT`, `FILES`, the final loop) unchanged.

```js
async function remoteSize(url) {
  try {
    const head = await fetch(url, { method: "HEAD" });
    if (!head.ok) return -1;
    const cl = Number(head.headers.get("content-length"));
    if (Number.isFinite(cl) && cl > 0) return cl;
    const xl = Number(head.headers.get("x-linked-size"));
    return Number.isFinite(xl) && xl > 0 ? xl : -1;
  } catch {
    return -1;
  }
}

async function download(rel) {
  const dest = join(OUT, rel);
  const url = `${BASE}/${rel}`;
  const expected = await remoteSize(url);
  if (existsSync(dest)) {
    const local = statSync(dest).size;
    // Complete when local matches remote, or remote size is unknown but local is non-empty.
    if (local > 0 && (expected === -1 || local === expected)) {
      console.log(`  skip ${rel} (complete, ${local} bytes)`);
      return;
    }
    console.log(`  refetch ${rel} (local ${local} != remote ${expected})`);
  }
  mkdirSync(dirname(dest), { recursive: true });
  const res = await fetch(url);
  if (!res.ok) throw new Error(`GET ${url} -> ${res.status} ${res.statusText}`);
  await pipeline(res.body, createWriteStream(dest));
  const got = statSync(dest).size;
  if (expected > 0 && got !== expected) {
    throw new Error(`size mismatch after download ${rel}: got ${got}, expected ${expected}`);
  }
  console.log(`  ok   ${rel} (${(got / 1e6).toFixed(1)} MB)`);
}
```

## Task 2: Bundle smoke test (`scripts/ci-smoke.mjs`)

**Files:**
- Create: `scripts/ci-smoke.mjs`

**Interfaces:**
- Consumes: a built `.next/standalone/server.js` (produced by `desktop:build`) with `public/` assets copied in.
- Produces: `node scripts/ci-smoke.mjs` exits `0` when every listed URL serves 200, non-zero otherwise. Honors `SMOKE_PORT` (default `3399`).

- [ ] **Step 1: Create `scripts/ci-smoke.mjs`**

```js
#!/usr/bin/env node
// Boots the built Next.js standalone server and asserts every bundled offline
// asset serves HTTP 200 — proving the bundle is complete before publishing.
// Exits non-zero on any failure. Does NOT exercise the editor in a browser.
import { spawn } from "node:child_process";
import { existsSync } from "node:fs";
import { join } from "node:path";

const root = join(import.meta.dirname, "..");
const standaloneDir = join(root, ".next", "standalone");
const serverJs = join(standaloneDir, "server.js");
if (!existsSync(serverJs)) {
  console.error(`missing ${serverJs} — run \`bun run desktop:build\` first`);
  process.exit(1);
}

const PORT = process.env.SMOKE_PORT ?? "3399";
const base = `http://127.0.0.1:${PORT}`;
const PATHS = [
  "/api/health",
  "/projects",
  "/editor/smoke-test",
  "/fonts/local/manifest.json",
  "/sfx/manifest.json",
  "/ort/ort-wasm-simd-threaded.jsep.wasm",
  "/models/onnx-community/whisper-base/config.json",
  "/models/onnx-community/whisper-base/tokenizer.json",
  "/models/onnx-community/whisper-base/onnx/encoder_model_q4.onnx",
];

const child = spawn(process.execPath, [serverJs], {
  cwd: standaloneDir,
  env: { ...process.env, PORT, HOSTNAME: "127.0.0.1" },
  stdio: "inherit",
});

async function status(path) {
  // Prefer HEAD; some handlers 405 HEAD, so fall back to GET.
  for (const method of ["HEAD", "GET"]) {
    try {
      const r = await fetch(`${base}${path}`, { method });
      if (r.status !== 405) return r.status;
    } catch {
      /* retry with GET, then report -1 below */
    }
  }
  return -1;
}

let failed = false;
try {
  const deadline = Date.now() + 30000;
  for (;;) {
    try {
      const r = await fetch(`${base}/api/health`);
      if (r.ok) break;
    } catch {}
    if (Date.now() > deadline) throw new Error("server did not become healthy within 30s");
    await new Promise((r) => setTimeout(r, 500));
  }
  for (const p of PATHS) {
    const s = await status(p);
    const ok = s === 200;
    console.log(`${ok ? "PASS" : "FAIL"} ${String(s).padStart(3)}  ${p}`);
    if (!ok) failed = true;
  }
} catch (e) {
  console.error(`smoke test error: ${e.message}`);
  failed = true;
} finally {
  child.kill();
}
process.exit(failed ? 1 : 0);
```

## Task 3: GitHub Actions workflow (`.github/workflows/build.yml`)

**Files:**
- Create: `.github/workflows/build.yml`

**Interfaces:**
- Consumes: `bun run desktop:build`, `node scripts/ci-smoke.mjs`, and the `version` field of `src-tauri/tauri.conf.json`.

- [ ] **Step 1: Create `.github/workflows/build.yml`**

```yaml
name: build
on:
  push:
    branches: [master]
    tags: ["v*"]
  pull_request:
    branches: [master]
  workflow_dispatch:

concurrency:
  group: build-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: write

jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: "1.2.18"

      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: x86_64-pc-windows-msvc

      - uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri

      - name: Cache Whisper model
        uses: actions/cache@v4
        with:
          path: public/models/onnx-community/whisper-base
          key: whisper-base-q4-v1-${{ hashFiles('scripts/fetch-whisper.mjs') }}

      - name: Verify tag matches app version
        if: startsWith(github.ref, 'refs/tags/v')
        shell: bash
        run: |
          tag="${GITHUB_REF_NAME#v}"
          ver=$(node -p "require('./src-tauri/tauri.conf.json').version")
          echo "tag=$tag tauri.conf version=$ver"
          if [ "$tag" != "$ver" ]; then
            echo "::error::Tag v$tag does not match tauri.conf.json version $ver"
            exit 1
          fi

      - name: Install dependencies
        run: bun install

      - name: Build desktop installer
        run: bun run desktop:build

      - name: Smoke test bundle
        run: node scripts/ci-smoke.mjs

      - name: Upload installer artifact
        if: ${{ !startsWith(github.ref, 'refs/tags/v') }}
        uses: actions/upload-artifact@v4
        with:
          name: OpenCut-installer
          path: src-tauri/target/release/bundle/nsis/*.exe
          if-no-files-found: error

      - name: Publish release
        if: startsWith(github.ref, 'refs/tags/v')
        uses: softprops/action-gh-release@v2
        with:
          files: src-tauri/target/release/bundle/nsis/*.exe
          generate_release_notes: true
          fail_on_unmatched_files: true
```
